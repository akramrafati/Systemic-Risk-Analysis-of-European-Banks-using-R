# Systemic-Risk-Analysis-of-European-Banks-using-R
Developed an empirical risk analysis in R comparing Deutsche Bank and Erste Group Bank AG using daily stock market data from Yahoo Finance.
Applied descriptive statistics, DCC-GARCH, dynamic beta, Marginal Expected Shortfall (MES), Long-Run MES (LRMES), and SRISK to evaluate market and systemic risk relative to the MSCI ACWI benchmark. The project demonstrates the implementation of econometric risk models and the interpretation of financial risk measures using real-world data.
